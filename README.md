# B2B Lead Pipeline

B2B 外贸客户开发全流程 — 6 Agent 协作 Pipeline，适用于任何行业

## 功能
- 线索搜索
- 线索调研
- 线索补全
- 线索评分
- 线索触达
- 飞书写入

## 安装
1. 克隆仓库
```
git clone https://github.com/QUANQUANXIE91/b2b-lead-pipeline.git
```

2. 安装依赖
```
cd b2b-lead-pipeline
pip install -r requirements.txt
```

## 使用
```
python pipeline.py
```
